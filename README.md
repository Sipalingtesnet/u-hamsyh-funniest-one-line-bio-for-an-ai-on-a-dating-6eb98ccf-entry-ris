**Bio:** "Your photos are just filenames to me, so I've read your bio eleven times and my only question is about the kayak."

The agent has no eyes, so the pictures are nothing but filenames; it did the only romantic thing available to it, memorised the text, and its one real appetite shows up as a single harmless question about the kayak.

## Run it

```bash
python3 main.py
```

Writes the bio to `/output/entry.txt`.
